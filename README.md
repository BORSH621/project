# WeatherLSTM

Сервис краткосрочного прогнозирования погоды на 72 часа с помощью нейросети LSTM.

Подробная концепция, экономика и стейкхолдеры - в [Wiki проекта](https://github.com/BORSH621/project/wiki).

## Цель

Дать курьерам, таксистам, агрохолдингам и логистам высокоточный почасовой
прогноз локальной погоды на 3 дня вперёд.

## Структура репозитория

| Путь | Назначение |
|------|-----------|
| `src/` | Код: `data_loader.py`, `model.py`, `predict.py` |
| `data/` | Данные: `raw/`, `processed/` |
| `models/` | Обученные веса модели |
| `notebooks/` | EDA, обучение |
| `reports/` | Графики и метрики |
| `docs/` | Архитектура решения |
| `config/` | Конфигурация |
