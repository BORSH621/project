# WeatherLSTM

Сервис краткосрочного прогнозирования погоды на 72 часа с помощью нейросети LSTM.
Решает проблему неточности глобальных физических моделей в локальных
микроклиматических аномалиях (гололёд, ливень, шквал).

Подробная концепция, экономика и стейкхолдеры — в [Wiki проекта](https://github.com/BORSH621/project/wiki).

## Цель

Дать курьерам, таксистам, агрохолдингам и логистам высокоточный почасовой
прогноз локальной погоды на 3 дня вперёд.

## Ключевые функции

- Загрузка и очистка исторических временных рядов (температура, влажность, давление).
- Обучение LSTM-модели прогнозирования на 72 часа.
- Визуализация прогноза и метрик качества (MAE, RMSE).
- Инференс: прогноз по новым данным за последние N дней.

## Технологии
